
# React Todo App

A responsive Todo application built with React for managing daily tasks.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Search tasks
- Filter tasks by status
- Task statistics
- Form validation
- Responsive design

## Tech Stack

- React
- JavaScript
- CSS
- Vite
- Lucide React
